## 三条最常忘的规矩

1. **提交前跑 `npm run check`**，七项全绿才能提交（pre-commit 钩子会强制）
2. **改了公式必须补 sympy 断言**，否则「算得对不对」没人验
3. **中文说明里不能出现裸 LaTeX**（`lim_{x→0}` 要写成 `lim(x→0)`），公式里不要塞中文
