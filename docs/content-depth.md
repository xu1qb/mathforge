# 内容厚度标准

对照教材单节的结构，一篇讲解要满足五项才算「对齐参考书」：

| 项 | 要求 |
|---|---|
| 严格定义 | 有 `definition` 字段，写成教材式定义 |
| 定理与公式 | ≥2 条 `theorems`，每条有陈述，能写公式的配公式 |
| 例题 | ≥2 个（`example` + `moreExamples`） |
| 易错点 | ≥2 条 `pitfalls` |
| 步骤 | ≥5 步 |
