# 内容厚度标准

对照教材单节的结构，一篇讲解要满足五项才算「对齐参考书」：

| 项 | 要求 |
|---|---|
| 严格定义 | 有 `definition` 字段，写成教材式定义 |
| 定理与公式 | ≥2 条 `theorems`，每条有陈述，能写公式的配公式 |
| 例题 | ≥2 个（`example` + `moreExamples`） |
| 易错点 | ≥2 条 `pitfalls` |
| 步骤 | ≥5 步 |

## 进度

```bash
npm run content:depth
```

## 分批计划

| 批次 | 范围 | 篇数 |
|---|---|---|
| 已完成 | 高数核心：求导法则、洛必达、等价无穷小、分部积分、定积分定义、牛顿-莱布尼茨、格林公式、级数判敛 | 8 |
| 第 2 批 | 高数剩余（极限/多元/重积分/曲线积分/级数） | ~20 |
| 第 3 批 | 线性代数（31 篇） | 31 |
| 第 4 批 | 概率统计（15 篇） | 15 |
| 第 5 批 | 现代数学（25 篇） | 25 |

## 说明

这项工作是纯内容工程：每篇都要重新组织定义、定理、两道例题和易错点，
不能靠脚本批量生成（会写出不通顺的套话）。每轮能稳定产出 4–8 篇。
