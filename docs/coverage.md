## 补内容的优先级建议

1. **欧氏几何 / 三角学**：初高中基础，竞赛小题常考，目前只有公式手册里的零散条目。
2. **拓扑学入门**：现代数学页已有零散内容，值得独立。
3. **随机过程**：概率线唯一的缺口。
4. 其余（代数几何、表示论等）超出非数学 A 考纲，暂不补。
