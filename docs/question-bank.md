# 出题机制

> 目标：每个知识点都能产出**大量不同**的题目，而不是几道题来回换。
> 检查：`npm run check` 第 5 步的 `check-variety.mjs`（多样性）、`check-generators.mjs`（渲染与书写）。

## 一、难度分级

参照高考「容易 : 中档 : 难 ≈ 3 : 5 : 2」与全国大学生数学竞赛（非数学类）初赛难度：

| 档位 | 特征 | 典型步数 | 对应水平 |
|---|---|---|---|
| **基础** | 概念直用、套一个公式 | 1 步 | 课本例题、会考 |
| **进阶** | 需要选方法、两步以上、含简单讨论 | 2–4 步 | 高考中档、考研基础 |
| **竞赛** | 构造、技巧性变形、多步推理 | 4 步以上 | 联赛一试、竞赛初赛 |

## 二、生成模型：题型 × 参数

旧机制是「模板池」：每个知识点固定 3–5 道题，抽到就重复（极限计算 90 次只出 4 道不同题）。

新机制是**参数化生成**：

```
题目 = 题型（3–7 种） × 随机参数（大区间整数/分数）
```

29 个知识点全部改造完毕，统一写在 `src/lib/practice-v2.ts`，通过 `mk()` 构造：

- 源码里用 `@` 代表反斜杠，`mk()` 自动还原
- LaTeX 里裸露的中文会自动包进 `\text{...}`
- 答案一律由参数**算出来**，不写死

## 三、答案复核（claims）

生成器除了题目和答案，还会给出**可复核声明**（`verify`），例如：

```ts
verify: { kind: 'limit', expr: 'sin(5*x)/x', variable: 'x', point: '0', claim: '5' }
```

`scripts/verify-generators.mjs` 抽样出题（每知识点每档 8 题），把声明交给
`scripts/verify-claims.py`，用 **sympy 独立重算**再和答案比对——不是字符串比对。

支持的声明类型：

| kind | 用来验什么 |
|---|---|
| `limit` | 极限值（含数列极限） |
| `derivative` | 求导结果 |
| `integral` | 定积分值 |
| `value` | 任何可算的表达式（面积、体积、概率、期望…） |
| `roots` | 两根之和/积/较大根（韦达） |
| `gcd` / `lcm` / `mod` | 数论运算 |
| `convergence` | p 级数 / 几何级数 / 交错级数的敛散性 |
| `parity` | 函数奇偶性 |
| `ode` | 一阶线性方程通解（代入残差为 0） |
| `interval` | 不等式解集：把答案文本解析成谓词，与真实解集在采样点上比对 |
| `property` | 性质判定：奇偶性、单调区间、值域下界、向量垂直、Fibonacci 奇偶、e 型极限、二阶常系数方程 |

当前覆盖率：**约 708 / 720（98%）**，30 个知识点全部有可复核声明，连续多轮运行零失败。

剩余未覆盖的是少数融合题分支（数字谜、对数型极限等），属于「能出题但难独立验算」的部分。

**已知被这套复核抓到的真实 bug**：

1. 特殊角生成器会产出 `tan 15°`、`sin 190°` 这类表里没有的角，答案直接变成 `'-0'`；
2. `cos2α` 生成器对结果取了绝对值，导致 `cos2α` 为负时答案错误；
3. `xⁿ·sin(x)` 的奇偶判断写反了（`sin` 是奇函数，但 `xⁿ` 的奇偶取决于 n），间歇性出错；
4. 傅里叶系数 `a₀` 少乘了 `2/T`，只有 T=2 时碰巧正确；
5. 棣莫弗定理表里 `z⁶` 在 θ=90° 的实部写成 `1`，实际是 `cos 540° = -1`。

复核器自身也修过两次：

- 重根时 `sympy.solve` 只返回一个解，导致「两根之积」算错 → 改用韦达定理；
- 生成器有保留两位小数的答案，严格相等会误判 → 数值比较放宽容差。

新增题型时，**能给出 verify 就一定要给**；给不出说明这道题没法自动验证，要标出来。

## 四、多样性门槛

`check-variety.mjs`：每个知识点抽 60 次，要求

- 全局平均去重率 **≥ 60%**
- 每个知识点 **≥ 20 道不同题**

当前：**83.9%**（1460/1740），最低的知识点也有 40/60。

## 五、新增题型的写法

1. 在 `src/lib/practice-v2.ts` 加 `genXxxV2`，用 `mk({...})` 构造；
2. 参数要**出现在 LaTeX 里**，否则去重会把它当成同一题；
3. 答案必须由参数算出来；
4. 在 `generatePracticeQuestion` 里把对应 `case` 指到新生成器；
5. 跑 `npm run check`，确认 `generators` 与 `variety` 都通过。
## 五、综合创新题（跨知识点融合）

除了单点参数化，还有一类**结构融合题**：不靠参数组合，而是把两个知识点的结构拼在一起，
生成竞赛风格的复合题（生成器 `genFusion`，知识点 key = `fusion`）。

| 融合 | 题目结构 |
|---|---|
| 数列 × 数论 | aₙ = aⁿ 的余数（找 mod 周期）、个位数字（4 循环） |
| 数论 × 组合 | 1..N 中与 6 互素的个数（容斥原理） |
| 数列 × 不等式 | aₙ = n/(n²+a²) 的最大值（均值不等式 + 取等条件） |
| 矩阵 × 递推 | 用 Fibonacci 转移矩阵求 Fₙ |
| 概率 × 组合 | 同时取两球同色的概率（组合数之比） |
| 极限 × 指数 | lim(1+k/n)^(mn) = e^(km) |
| 复数 × 三角 | 棣莫弗定理求 Re(zⁿ) |
| 导数 × 不等式 | f(x)=x³−3ax 的极小值（求导 + 二阶导判定） |
| 级数 × 概率 | 几何分布的期望 = 1/p（级数求和） |
| 数论 × 数列 | n²+n 恒被 2 整除（连续整数之积） |

这类题只有「竞赛」档，结构固定但参数随机，答案全部可验算。

## 六、难度梯度

`check-difficulty.mjs` 抽样 12 次/档，检查步骤数是否逐级递增：

- 基础：按题型原样给步骤（约 2.6 步）
- 进阶：多加一步「方法：先确定可直接套用的公式」
- 竞赛：多了「思路选择」与「结果回代检验」两步（约 4.7 步）

当前：基础 2.63 步 → 竞赛 4.67 步，30 个知识点**无倒挂**。

### 融合题按难度分层

| 档位 | 融合维度 | 题型数 | 步骤 |
|---|---|---|---|
| 进阶 | 两科融合 | 6 | 4 步 |
| 竞赛 | 两科 + 三科融合 | 15 | 5 步 |

三科融合示例：

| 组合 | 题目 |
|---|---|
| 数列 × 数论 × 组合 | 1..N 中有多少 n 使 2ⁿ ≡ 1 (mod 7)（周期 3 + 计数） |
| 矩阵 × 递推 × 极限 | Fₙ₊₁/Fₙ 的极限 = 黄金分割比 |
| 三角 × 复数 × 数列 | Σcos(kπ/3) 的周期求和 |
| 数论 × 组合 × 数列 | 1..N 中既是 3 的倍数又是奇数的个数 |
| 向量 × 矩阵 × 数列 | vₖ₊₁ = Mvₖ 迭代求分量 |

### 四科超融合（竞赛档）

| 组合 | 题目 | 答案形式 |
|---|---|---|
| 数论 × 组合 × 概率 × 数列 | 1..N 随机取数，与 6 互素的概率 | 分数（容斥计数 / N） |
| 矩阵 × 递推 × 数论 × 数列 | 用转移矩阵求 Fₙ，判断奇偶 | 奇 / 偶（mod 3 周期） |
| 向量 × 矩阵 × 三角 × 复数 | 向量旋转 90° 后的模 | 整数（旋转保模） |
| 极限 × 三角 × 数列 | lim n·sin(k/n) | k |

### 扩增后的三科融合

新增「三角 × 数论 × 组合」（sin(nπ/6)=1/2 的计数）与「概率 × 数论 × 组合」（3 的倍数且为奇数的概率）。

|---|---|---|
| 进阶 | 6 | 两科 |
| 竞赛 | 20 | 两科 / 三科 / 四科 |
